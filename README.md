# 林醫師薪水分析工具

奇美醫院急診部薪資試算的純前端工具，單檔 HTML，無後端。

## 功能

| 分頁 | 用途 |
|------|------|
| 📝 加班單產生器 | 依班表產生加班申請資料 |
| 📅 用班表計算車馬費 | 上傳班表，自動計算車馬費 |
| 📊 提成月報 | 月度提成與收入彙總 |
| 🚗 車馬費計算器 | 單筆班別車馬費快速試算 |

## 使用方式

直接用瀏覽器開 `index.html` 即可，所有計算在本機執行，資料不上傳。

## 開發

- 單一檔案：`index.html`（HTML + CSS + JavaScript）
- 修改後 commit + push 即完成更新

## 隱私

- 所有試算僅在瀏覽器本機進行
- 不蒐集、不上傳任何個人或薪資資料
- Repo 為 private，僅作者與受邀者可存取
