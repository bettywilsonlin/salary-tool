# 急診薪水分析工具

把薪資條 PDF 拖進網頁，就自動幫你逐月攤開來對照。單一 HTML 檔，沒有後端，**所有計算都在你自己的瀏覽器裡跑**。

> 🔗 線上使用：https://bettywilsonlin.github.io/salary-tool/

> ⚠️ **免責聲明**：本工具為個人開發的試算小工具，**非任何醫院或機構的官方產品**。所有計算結果僅供個人參考，實際薪資、車馬費、加班費應以人事單位公告為準。使用者因使用本工具所做之任何決策，作者不負任何法律責任。

## 怎麼用

1. **把薪資條 PDF 拖進畫面上的框**，可以一次拖好幾個月。
2. 想一次讀整個資料夾的話，按「📂 ＋ 加資料夾」，選你放薪資條的資料夾。提成月報、值班表也可以各加一個資料夾。
3. 上面五個頁籤看不同的東西。

網頁上有一塊「📖 使用說明」，點開就有完整說明，不必回來看這份 README。

## 五個頁籤

| 頁籤 | 用途 |
|------|------|
| 💰 薪資總覽 | 上傳的薪資條逐月攤開來對照 |
| 📅 用班表計算車馬費 | 上傳值班表，整個月的車馬費自動算 |
| 📊 提成月報 | 上傳提成月報，看每月的提成 |
| 🚗 車馬費計算器 | 單一班別快速試算 |
| 🧮 總薪水試算 | 車馬費加提成的估算，跟薪資條實領對照 |

## 算出來跟薪資條對不上怎麼辦

**以你收到的薪資條為準。** 對不上的月份，畫面上會出現一個黃框寫出差多少錢，並在那個月的欄位標上 ⚠️。

那代表這個工具讀錯或算錯了，不是薪資條錯了。**請不要拿這裡的數字去跟人事室對帳。**

## 你的資料會跑到哪裡去

哪裡都不會去。這個網頁沒有伺服器，PDF 與 Excel 是在你自己的瀏覽器裡讀的，讀完就顯示在畫面上。

不信的話按 F12 打開「網路」分頁看，開這個工具**不會對外連任何地方**（連字型和函式庫都是內嵌的）。

### 記憶預設是關的

預設**不會**在你的電腦上留下任何東西，關掉網頁就沒了。

要它記住，得自己勾「記住這台電腦上的資料」。勾了之後資料存在**你這台電腦的瀏覽器裡**（IndexedDB），下次開啟自動載入。

| 情境 | 會怎樣 |
|---|---|
| 沒勾記憶 | 關掉網頁資料就沒了，電腦上不留任何東西 |
| 勾了記憶，同事跟你用同一台電腦同一個瀏覽器 | **會看到彼此的資料**（瀏覽器不分使用者）→ 所以共用電腦不要勾 |
| 同一人在公司 Chrome、家裡 Safari | 兩邊各自獨立、不會同步（這是設計如此，不是壞掉） |
| 換電腦 | 用「⬇️ 匯出備份」下載一個檔案，到另一台按「⬆️ 匯入備份」放回去 |

### 🔴 在共用電腦上用之前先看這段

值班室、醫師室那種大家都會用的電腦：

- **不要勾「記住這台電腦上的資料」**
- 不小心勾了，或想確定沒留下東西，按「🗑 清除這台電腦上的資料」
- 匯出的備份檔裡面就是你的薪資，**請當成薪資條一樣保管**，不要留在共用電腦上

## 技術說明

- **單一檔案** `index.html`，約 3.2 MB。pdf.js、xlsx、docx 全部內嵌，**零外部請求**
- 有 Content Security Policy，`connect-src 'none'`、`form-action 'none'`——資料送不出去
  - 誠實聲明：十個 CSP 指令裡 `frame-ancestors` 放在 `<meta>` 裡瀏覽器會忽略，GitHub Pages 又設不了 HTTP 標頭，所以那一個在這裡實際上是無效的。其餘九個實測有效
- 讀資料夾用的是 File System Access API。**瀏覽器不支援時，那顆「加資料夾」按鈕不會出現**，拖檔案仍然可以用。實測過可以的是 Chrome（其他瀏覽器沒測過，但不支援也只是少一顆按鈕，不會壞掉）
- 這份 `index.html` 是產生出來的，不是手改的。原始碼與產生流程不在這個 repo
