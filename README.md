# 急診薪水分析工具

急診醫師薪資試算的純前端工具，單檔 HTML，無後端。

> ⚠️ **免責聲明**：本工具為個人開發的試算小工具，**非任何醫院或機構的官方產品**。所有計算結果僅供個人參考，實際薪資、車馬費、加班費應以人事單位公告為準。使用者因使用本工具所做之任何決策，作者不負任何法律責任。

## 功能

| 分頁 | 用途 |
|------|------|
| 📝 加班單產生器 | 依班表產生加班申請資料 |
| 📅 用班表計算車馬費 | 上傳班表，自動計算車馬費 |
| 📊 提成月報 | 月度提成與收入彙總 |
| 🚗 車馬費計算器 | 單筆班別車馬費快速試算 |

## 使用方式

直接用瀏覽器開 `index.html` 即可，所有計算在本機執行，資料不上傳。

## 資料儲存與隱私

- 上傳的值班表 / 提成表會記憶在**你自己的瀏覽器**（IndexedDB），下次開啟自動載入
- 已記憶清單按類型分組顯示，可單筆刪除或一鍵清除全部
- 資料只存在你的瀏覽器，**不上傳任何伺服器、不蒐集任何個人或薪資資料**

### 常見情境

| 情境 | 會怎樣 |
|---|---|
| 同事 A、B 用同一台電腦同一個瀏覽器 | 會看到彼此資料（IndexedDB 不分使用者，只分瀏覽器）→ 請用自己的電腦/瀏覽器 |
| 同一人在公司 Chrome、家裡 Safari | 兩邊資料各自獨立、不會同步（功能限制，不是 bug） |
| 瀏覽器無痕模式 / 清快取 | 資料消失（這是設計如此） |

### ⚠️ 公共電腦請使用無痕模式

若你在醫院公共電腦、值班室共用電腦、或任何不是你個人專屬的瀏覽器使用本工具，**請務必開啟無痕／隱私模式**（Chrome：Ctrl/Cmd+Shift+N；Safari：Cmd+Shift+N）。

無痕模式下：
- 你的薪資 / 提成資料**不會殘留**在那台電腦上
- 關閉視窗後資料即消失，下次開啟需重新上傳
- 避免下一個使用者看到你的個人資料
